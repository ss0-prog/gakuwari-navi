# 学割NAVI(gakuwari.site)WordPress テーマ

大学生・高校生・中学生向けの学割情報ポータルサイト「学割NAVI」のテーマです。個人で開発・運営しています。

- サイト: https://gakuwari.site
- 作成者: SakaShugo

## 内容

`origintheme__ver.3.1/` が、WordPress のテーマ一式です(WordPress 本体・プラグイン・設定ファイル・画像のアップロードは、含みません)。

| 区分 | 主なファイル |
|---|---|
| トップ・共通 | `index.php`、`header.php`、`footer.php`、`sidebar.php`、`functions.php` |
| 学割の一覧・個別 | `archive-service.php`、`single-service.php`、`taxonomy-service-type.php`、`taxonomy-age-type.php`、`taxonomy-region-type.php`、`search.php` |
| おすすめ情報・お知らせ | `archive-recommendation.php`、`single-recommendation.php`、`archive-news.php`、`single-news.php` |
| 固定ページ | `page-concept.php`、`page-company.php`、`page-contact*.php`、`page-form*.php`、`404.php` |
| CSS・JavaScript | `common/css/`、`common/js/`(jQuery、slick、fancybox を使用) |

## 使っている技術

PHP / WordPress(テーマ開発、カスタム投稿タイプ・タクソノミー、Smart Custom Fields)、HTML / CSS(SCSS)、JavaScript(jQuery)。

## 注意

- このリポジトリは、本番サイトの、ある時点のテーマを元にしています(2026年10月12日のバックアップ)。
